# ChromaSniff CAD Documentation

This directory documents the mechanical CAD architecture for the ChromaSniff V1.1 handheld and its quadruped robotic integration.

## Source files

- `ChromaSniff_CAD_Handheld.py` — parametric handheld/payload CAD skeleton.
- `ChromaSniff_Robot_Integration_v1.py` — quadruped integration and payload validation.
- `ChromaSniff_CAD_Master_Design_Brief_claude(1).md` — mechanical design brief and validation requirements.

## CAD status

The project is at a parametric concept / integration stage. Envelope dimensions are placeholders unless explicitly backed by a selected component STEP/datasheet. The next freeze gate is replacement of placeholders with real component geometry followed by mechanical, thermal, electrical and serviceability validation.
